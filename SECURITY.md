# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
If you discover a potential cryptographic vulnerability or security flaw in the PMMR implementation, please report it responsibly by opening a confidential security advisory on GitHub or contacting the maintainers directly.
Please include:
- A proof of concept or reproduction code.
- Impact assessment (e.g. proof forgery, second-preimage attack, memory exhaustion).
